# AUIE — Among Us Infinite Editor
A Python program that lets you configure Among Us lobby settings without restrictions.

### Installation
***The program currently only supports Windows!***\
Just download the "AUIE — Among Us Infinite Editor.pyw" file and run it.

You MUST have Python, minimum v3.14.0.\
You "must" have Among Us v19s (or v19.0.0).\
_I haven't really tested with other Among Us versions so I suppose they should work, but probably only if they don't add any other roles._
